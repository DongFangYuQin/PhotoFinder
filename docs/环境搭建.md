# 环境搭建：从零开始装开发工具

> 给新手的照做指南。你不需要看懂每一步的原理，按顺序点就行。
> 每一步做完在方框里打个勾，全部做完告诉我。

预计总时间：**1～2 小时**（大部分是等下载）。
需要下载大约 **3～4 GB**，请确保网络稳定。

---

## 第 0 步：先确认一件事（重要）

按 `Ctrl + Shift + Esc` 打开任务管理器 → 点左侧"性能" → 点"内存"。

看最上面写的总量是多少 GB：

- **16 GB 或以上** → 很好，按本文档正常走
- **8 GB** → 能跑，但会比较卡，后面我会把设置调低
- **不到 8 GB** → 先告诉我，我们得想办法

顺便记一下：**C 盘要留出至少 15 GB**（你的 C 盘现在空闲 233 GB，够用）。

☐ 我看过了，内存是 ______ GB

---

## 第 1 步：下载 Android Studio

1. 打开浏览器，访问：**https://developer.android.com/studio**
2. 页面上有一个醒目的下载按钮，点它
3. 会看到一个"同意条款"的勾选框，**勾上**，然后点下载按钮
4. 下载的文件名字类似 `android-studio-2025.x.x.x-windows.exe`，大约 **1.2 GB**

> ⚠️ 如果页面是英文的不要慌，认准那个大大的绿色/蓝色下载按钮就行。
> ⚠️ 如果下载很慢，可以换个时间再试，或者用迅雷之类的下载工具。别去第三方网站下，有被塞病毒的风险。

☐ 下载完成

---

## 第 2 步：安装 Android Studio

双击刚才下载的 `.exe` 文件。

1. 一路点 **Next**
2. 到了选择安装位置的界面（写着 `Android Studio` 和路径的那一页）：
 - **建议改成 D 盘**，比如 `<Android Studio 目录>\Android Studio`
 - 因为 Android Studio 本身要占 4～5 GB，放 D 盘给 C 盘留空间
3. 继续 Next，最后点 **Install**
4. 装完后勾选 **Run Android Studio**，点 **Finish**

☐ 安装完成

---

## 第 3 步：首次启动的"设置向导"

第一次打开它会问你一堆问题，**大部分直接点 Next 就行**，注意这两处：

1. 问安装类型（Install Type）时，选 **Standard（标准）** —— 它会自动装好 SDK 和模拟器
2. **仔细看它列的"要下载的东西"和"安装位置"**：
 - 它会列出 Android SDK、模拟器等等，显示大概要下 **2～3 GB**
 - SDK 的默认位置通常在 `C:\Users\你的用户名\AppData\Local\Android\Sdk`
 - **建议把 SDK 位置也改到 D 盘**，比如 `<Android Studio 目录>\Sdk`
 - 改法：在那个列表页面通常能改路径，或者点 Cancel 后手动设置。**如果找不到改的地方，就用默认的，不用纠结**
3. 一路 Next，等它下载完（这一步最慢，可能 20～60 分钟，可以去喝杯水）

☐ 设置向导完成，能看到 Android Studio 的主界面

---

## 第 4 步：确认要用的安卓版本装了

1. 在 Android Studio 主界面，点右上角或菜单里的 **More Actions**（更多操作）→ **SDK Manager**
 - 或者：菜单 **Tools → SDK Manager**
2. 会出现两个标签页，看第一个 **SDK Platforms**：
 - 勾选 **Android 16.0 (API 36)**（如果显示的是 Android 16 或 Android 15 都可以）
 - 下面的 **Show Package Details** 不用点开
3. 切到第二个标签 **SDK Tools**，确认这几项打了勾：
 - ☑ Android SDK Build-Tools
 - ☑ Android SDK Platform-Tools（这个里面有 `adb`，连手机要用）
 - ☑ Android SDK Command-line Tools (latest)
 - ☑ Android Emulator（模拟器，暂时用不上，但装了方便）
4. 点 **Apply**，等它下载完

☐ SDK 组件装好

---

## 第 5 步：把手机准备好

### 5.1 打开手机里的"开发者选项"

1. 打开手机 **设置** → **关于手机**
2. 找到 **版本号**（或"内部版本号"），**连续点击 7 次**
3. 会提示"您已处于开发者模式"

### 5.2 打开 USB 调试

1. 回到 **设置** → **系统** → **开发者选项**（不同手机位置略有不同，有的在"设置→更多设置"里）
2. 找到 **USB 调试**，打开它
3. 如果还有 **"USB 安装"**，也一起打开

### 5.3 用数据线连电脑

1. 用数据线把手机接到电脑
2. 手机上会弹一个窗口问"**是否允许 USB 调试**"，勾选"始终允许"，点**允许**
3. **注意**：有些数据线只能充电、不能传数据。如果电脑一直认不出手机，**换一根线试试**（这是新手最常踩的坑）

☐ 手机已连接

## 第 6 步：创建一个临时项目，用来告诉我版本号

我需要知道你装的 Android Studio 的**完整版本号**，这样才能把项目配置写成匹配的。

1. 在 Android Studio 欢迎界面点 **New Project**（新建项目）
2. 模板列表里选 **Empty Activity**，点 Next
3. 填三个地方：
 - **Name**：随便填，比如 `VersionCheck`
 - **Package name**：随便，比如 `com.test.versioncheck`
 - **Save location**：随便找个地方，比如 `D:\temp`
 - **Language**：选 **Kotlin**
 - **Minimum SDK**：选 **API 36** 或列表里最上面的
 - Build configuration language：选 **Kotlin DSL**
4. 点 **Finish**，等右下角进度条跑完
5. 跑完后，看 **菜单 Help → About**，会显示版本号，比如 `Android Studio Rabbit 1 | 2025.2.1 Patch 1`

**把这个版本号原样发给我。**

## 常见问题

| 症状 | 怎么办 |
|---|---|
| 下载特别慢、卡在 Gradle 下载 | 国内网络问题，告诉我，我给你配国内镜像 |
| 提示 `JAVA_HOME` 相关错误 | 先别自己改，把完整报错发我 |
| 电脑认不出手机 | ① 换数据线 ② 换个 USB 口（优先插主板后面的口）③ 手机上把 USB 用途改成"传输文件" |
| 手机连上了但点运行没反应 | 看 Android Studio 底部有没有红色报错，发我 |
| 弹出"是否允许防火墙访问" | 点允许 |
| C 盘红了 | 告诉我，SDK 和 Gradle 缓存都要挪到 D 盘 |
| 汉化 | 菜单 **Settings → Plugins**，搜 `Chinese` 装中文语言包（可选，装了之后界面变中文） |

## 第 8 步：请你回头找我确认几件事

### 1. 为什么要回报版本号（说明）

安卓项目的"编译规则"（有几个文件的版本号）必须和 Android Studio 的版本对得上，
**对不上就编译不过**。我不知道你装的是哪一版，就只能瞎猜。所以这个必须由你告诉我。

### 2. 请你回报的信息

**（a）版本号**

菜单 **Help → About**，把显示的那一行原样抄给我，例如：

```
Android Studio Rabbit 1 | 2025.2.1 Patch 1
Build #版本号, built on ...
```

> 小技巧：About 窗口里能选中文字，直接 `Ctrl + C` 复制，然后粘贴给我。

**（b）SDK 装在哪**

菜单 **File → Settings**（或 `Ctrl + Alt + S`）→ 左边依次展开
**Languages & Frameworks → Android SDK**，
把 **Android SDK Location** 那一栏的路径抄给我，例如 `<Android Studio 目录>\Sdk`。

**（c）电脑内存多少 GB**（第 0 步）

**（d）手机型号 + 安卓版本**（手机 设置 → 关于手机）

### 3. 顺便确认你能看到开发文件

打开文件管理器，进到：`PhotoFinder\app\src\main\java\com\atri\photofinder`

如果你能看到 `model`、`data` 这几个文件夹，说明你已经能看到我写的代码了。
（现在还没法编译运行，因为我还没写编译配置——那要用到你的版本号。）
